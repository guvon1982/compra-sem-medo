# Capturas de tela (screenshots)

Coloque aqui as imagens usadas no README principal. Esta pasta existe para
versionar os prints da aplicação.

## Quais imagens adicionar

Tire os prints com a aplicação rodando (`npm run dev` → http://localhost:5173).
Use os nomes de arquivo abaixo para que os links do README funcionem direto:

| Arquivo | Tela | O que mostrar |
|---|---|---|
| `home.png` | Início (`/`) | Tagline + uma compra em andamento (com total e meta). |
| `listagem-compra.png` | Listagem → Minha compra | Itens com subtotal, total e barra de meta. |
| `listagem-catalogo.png` | Listagem → Catálogo | Produtos agrupados por categoria + busca. |
| `historico.png` | Listagem → Histórico | Lista de compras anteriores (ou o detalhe de uma). |
| `cadastro.png` | Cadastro (`/cadastro`) | Formulário preenchido (ou mostrando uma validação). |

> Opcional: um `demo.gif` curto (10–15s) percorrendo o fluxo "adicionar produto →
> ver total → finalizar" fica ótimo no topo do README.

## Como tirar o print

- **Windows:** `Win + Shift + S` (recorte) ou a ferramenta de Captura.
- Para enquadrar como celular (mobile-first), abra o **DevTools** (`F12`) →
  ícone de dispositivo (`Ctrl + Shift + M`) → escolha um aparelho (ex.: iPhone)
  e capture só a área do app.

## Como aparecem no README

Depois de colocar as imagens aqui, **descomente** o bloco de imagens na seção
"## Telas" do [`README.md`](../../README.md) na raiz do projeto.
