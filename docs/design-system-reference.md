Use a imagem anexada como referência visual principal do Design System do projeto Compra Sem Medo.

Antes de criar telas completas, implemente apenas a base visual do projeto em React com CSS organizado.

Crie os tokens de design com base nesta identidade:

Marca:
Compra Sem Medo

Conceito:
“Sua compra sob controle, sem susto no caixa.”

Estilo:
Mobile first, minimalista, clean, amigável, moderno, tecnológico, confiável e simples.

Fonte:
Inter.

Cores:
--color-green-primary: #22C55E;
--color-green-dark: #15803D;
--color-blue-primary: #2563EB;
--color-blue-light: #0EA5E9;
--color-orange-alert: #F97316;
--color-purple-support: #8B5CF6;
--color-background: #F8FAFC;
--color-surface: #FFFFFF;
--color-border: #E2E8F0;
--color-text-primary: #0F172A;
--color-text-secondary: #64748B;

Componentes iniciais:
Button, Input, Card, ProductItem, ShoppingListItem, BudgetProgress, Header, BottomNavigation, AlertMessage, EmptyState.

Regras:

- Criar componentes reutilizáveis.
- Usar HTML semântico sempre que possível.
- Evitar div desnecessária.
- Mobile first.
- Interface acessível.
- Estados visuais para sucesso, alerta, erro e informação.
- Não criar funcionalidades complexas ainda.
- Não implementar OCR, câmera ou backend nesta etapa.
- Criar apenas dados mockados quando necessário para visualização.
